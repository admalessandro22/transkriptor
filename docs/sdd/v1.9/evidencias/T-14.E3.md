## O que foi entregue

- **`consentimento_layout.py`** (puro, sem janela): `layout_consentimento(dpi) -> dict` com janela, fontes (20/15/12 px) e nove retângulos (`icone`, `titulo`, `mensagem`, `fonte_detectada`, `progresso`, `contagem`, `botao_sim`, `botao_nao`, `dica`) escalados por `dpi/96` e arredondados; DPI inválido cai em 96. Textos: título "Gravar esta reunião?", primário "Gravar esta reunião", secundário "Não gravar", contagem "Fecha em N s sem gravar". `descrever_fontes(fontes)` traduz **apenas** nomes de fonte do detector (`titulo`/`extensao` → Google Meet, `zoom` → Zoom, `microfone` → microfone em uso); qualquer outra string é ignorada — nunca título de janela nem nome de participante. Constantes base em `config.py` (`CONSENTIMENTO_*`).
- **`consentimento_controles.py`** (Win32): thread do diálogo vira ciente de DPI só nela (`SetThreadDpiAwarenessContext` PER_MONITOR_AWARE_V2, restaurada ao sair), `GetDpiForSystem`, ícone `transkriptor.ico` via `LoadImageW` (classe + `STATIC`/`SS_ICON` no corpo), `msctls_progress32` com `PBM_SETRANGE32`/`PBM_SETPOS` decrescente em ms, `AdjustWindowRectEx` para a moldura, fontes Segoe UI escaladas, `WM_CTLCOLORSTATIC` para texto sobre o branco da janela, liberação de fontes e ícone. Cada recurso falha em silêncio e cai no comportamento anterior (sem ícone, sem barra, escala 96).
- **`consentimento_gravacao.py`**: `pedir_consentimento(timeout_seg, fontes=())` e `_mostrar_dialogo(timeout_seg, fontes=(), dpi=None)`; IDs (`_ID_SIM=1001`, `_ID_NAO=1002`, `_ID_COUNTDOWN=1003`), timers, `_WS_EX_TOPMOST`/`_WS_EX_TOOLWINDOW`, fail-closed (`resposta_autoriza_gravacao`, `except → False`) inalterados. No `WNDPROC` só mudou o corpo do timer de 50 ms (agora `atualizar_contagem`) e entrou o ramo cosmético `WM_CTLCOLORSTATIC`; as portas de saída (Sim/Não/fechar/timeout/cancelar) são as mesmas. Sem `fontes`, chama `_mostrar_dialogo(timeout)` como na v1.8, para dublês antigos de um argumento.
- **`app_ciclo_reuniao.py`**: `_pedir_e_iniciar` passa `detector.fontes_da_reuniao` via `functools.partial(pedir_consentimento, fontes=…)`; o seam `_pedir_consentimento` dos testes continua sendo chamado sem argumentos.
- Extração em dois módulos porque `consentimento_gravacao.py` tinha 445 linhas e o limite é 500 (`test_limite_linhas`); o bloco duplicado de `CreateWindowExW.argtypes` foi removido.

## Gate

- [x] Layout escala linearmente com o DPI; botão primário ≥ 36 px × escala; primário mais largo que o secundário.
- [x] Fail-closed inalterado: timeout, Não, fechar, erro e cancelamento continuam devolvendo `False`; `resposta_autoriza_gravacao` é o único caminho para `True`.
- [x] Fontes detectadas nunca expõem título de janela nem nome (`test_fontes_nunca_incluem_titulo_ou_nome`).
- [x] Nenhum callback sob `self._lock` (`tests/test_lock_sem_callback.py`).

## Limitações

- O DPI real do monitor do usuário só é honrado em Windows 10 1703+ (API por thread); em versões anteriores a janela fica em 96 e o Windows a escala como antes.
- As capturas forçam o DPI por parâmetro (processo continua sem DPI-awareness global); a captura com o Windows de fato em 150/200 % fica para o gate G.
